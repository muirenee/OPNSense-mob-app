# Roadmap

## 0.1 Foundation — complete
- Profiles and secure API credentials
- Connection test and themes
- App shell and live diagnostic dashboard

## 0.2 Operations visibility — complete
- Saved profile selector / edit / delete
- Capability probing
- Gateways and interface throughput
- Services status
- Firewall Automation rules and live log

## 0.3 Safe management — complete
- Rollback-safe Firewall Automation rule enable/disable
- Guarded service start/stop/restart
- DHCP leases with provider detection
- ARP / NDP neighbors
- Firewall aliases and NAT read-only
- Active firewall states read-only
- Per-profile app audit trail

## 0.4 VPN and diagnostics — complete in source
- WireGuard status/peers
- OpenVPN sessions
- IPsec status/Phase 1 sessions
- Guarded VPN service controls
- Ping jobs
- Traceroute
- Reverse DNS lookup
- Packet capture jobs and PCAP download
- Routing table
- Expanded API capability matrix

## 0.5 Advanced configuration
- NAT add/edit/delete with transaction safeguards
- Alias add/edit/delete
- Firewall rule add/edit/delete/reorder
- DHCP reservations/static mappings
- Optional selected-state kill with strong confirmation
- Configuration backup/download before high-risk changes

## 0.6 Captive Portal and analytics
- Active sessions
- Session disconnect
- Insight/NetFlow views
- Health notifications

## 1.0 Production hardening
- Biometric app lock
- Certificate fingerprint pinning
- Refined multi-firewall UX
- Exportable audit trail
- Backup/restore guardrails
- Signed Android/iOS release process
